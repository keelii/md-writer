# Zen Writer

> 禅意写作 — 一个简洁、纯粹的 Markdown 写作应用

Zen Writer 是一款轻量级、纯浏览器端的所见即所得 Markdown 编辑器。无需面对满屏的语法标记，也无需在编辑器与预览窗口之间反复切换。直接在文档中写作，标题、列表、代码、表格、公式和图表都会自然呈现。

## 功能特点

- Write naturally — 编辑即预览，让 Markdown 语法隐于体验之中。
- Rich formatting — 标题、嵌套列表、引用、文本样式、链接和表格，满足日常写作与技术文档需求。
- Code, beautifully presented — 语法高亮、语言切换、一键复制，让代码成为文档的一部分。
- Beyond plain text — 原生支持数学公式、Mermaid 图表、SVG 绘图、嵌入页面和脚注，让复杂内容自然融入正文。
- Designed for long-form writing — 内置目录面板与垂直韵律网格，让长文档保持清晰的结构与统一的排版。
- Images without friction — 通过文件选择或直接粘贴插入图片，并可接入自定义上传服务。
- Your content, your Markdown — 内容始终可以通过标准 Markdown 获取，方便保存、同步与迁移。
